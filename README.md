# Space Garden Lady

An interactive, real-time GPU WebGL water simulation and 3D botanical spatial environment built with **Three.js**. This project features custom wave physics, interactive splash ripple mechanics, and dynamic lighting designed to showcase high-performance web graphics.

🔗 **Live Demo (Google Sites):** [Space Garden Lady Simulation](https://sites.google.com/view/space-garden-lady-simulation/full-page-embed)

---

## ✨ Features

* **GPU-Based Water Simulation:** Real-time wave equation solver executing custom vertex animations and normal map generation for realistic water ripples.
* **Interactive Physics:** Users can drag the 3D bottle across the pool or click directly on the water surface to trigger dynamic ripples and splashes.
* **Orbit & Zoom Controls:** Full camera manipulation powered by Three.js `OrbitControls` (Right-click to rotate, scroll wheel to zoom).
* **PBR Materials & Lighting:** Custom physical materials, shadow mapping, and environment reflections for an immersive visual experience.

---

## 🛠️ Tech Stack

* **Core Engine:** Three.js (r128)
* **Styling & UI:** Tailwind CSS, FontAwesome
* **Graphics & Shaders:** Custom JavaScript wave buffer simulation, Canvas Texture generators, and WebGL rendering pipeline.
